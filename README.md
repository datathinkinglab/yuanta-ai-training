# 유안타증권 AI 교육 허브

**경영 질문에서 현장 실행까지, AI로 혁신하는 유안타증권 업무 패러다임**

유안타증권의 임원, 본사 팀장, 지점장을 위한 생성형 AI 교육 사이트입니다. 2026 유안타증권 AX(AI Transformation) 역량 강화 프로그램의 교육 허브로, 대상별 HTML 강의 슬라이드를 한곳에서 열 수 있습니다.

## 교육의 방향

AI를 활용해 정보를 정리하는 것에서 출발하여, 근거를 확인하고 업무를 개선하며 실행 결과를 점검하는 과정으로 이어집니다. 임원의 경영 브리핑, 본사 팀장의 운영 프로세스 개선, 지점장의 영업 현장 실행을 공통 질문으로 연결합니다.

| 교육 대상 | 중심 역할 | 강의 주제 |
| --- | --- | --- |
| 임원 | 경쟁환경을 읽고 경영 질문과 실행 방향 설정 | AI로 읽는 경쟁환경, 경영 브리핑과 실행 리더십 |
| 본사 팀장 | 경영 질문을 부서의 업무 개선과 실행 과제로 구체화 | 경영 질문을 팀의 실행으로 |
| 지점장 | 영업 데이터를 해석하고 직원 코칭과 현장 실행에 연결 | AI와 함께 만드는 영업직원 코칭 대시보드 |

## 대상별 강의 안내

### 1. 임원 교육

공개 공시자료를 바탕으로 경쟁환경을 살펴보고, AI의 비교 분석 결과를 원문과 대조하며 경영 판단에 필요한 질문을 정리합니다. 분석 내용을 HTML 경영 브리핑 보드로 구성하고, 본사에서 추가로 확인할 과제와 실행 점검으로 연결합니다.

- 공개자료의 비교 기준과 근거 확인
- AI 분석 결과의 사실과 해석 구분
- 경영 브리핑 보드 제작 및 검토
- 부서 확인 과제와 실행 리더십 연결

**[임원 강의 슬라이드 열기](https://datathinkinglab.github.io/yuanta-ai-training/executives.html)**

### 2. 본사 팀장 교육

경영 질문을 부서의 실제 업무 흐름과 연결하고, 현재 업무의 지연·재작업·인계 지점을 살펴봅니다. AI를 활용해 개선안을 구체화한 뒤 팀 운영 관리 보드와 임원 보고용 제안으로 정리합니다.

- 현재 업무 흐름(AS-IS)과 병목 후보 분석
- 개선 업무 흐름(TO-BE)과 운영 기준 설계
- 부서 기능을 반영한 HTML 팀 운영 관리 보드 제작
- 업무 개선 제안, 시범 적용 계획 및 성과 점검

**[본사 팀장 강의 슬라이드 열기](https://datathinkinglab.github.io/yuanta-ai-training/team-leaders.html)**

### 3. 지점장 교육

가상의 영업직원 실적 데이터를 활용하여 직원의 변화와 면담 전 확인할 사항을 살펴봅니다. AI와 함께 코칭 대시보드를 만들고, 화면의 수치와 기능을 검증한 뒤 직원과의 대화 및 지원 방향으로 연결합니다.

- 실적 데이터의 의미와 변화 파악
- 면담을 위한 관찰과 질문 정리
- HTML 영업직원 코칭 대시보드 제작
- 데이터·계산·화면 기능 검증 및 수정
- 코칭 대화와 지점 현장 적용

**[지점장 강의 슬라이드 열기](https://datathinkinglab.github.io/yuanta-ai-training/branch-managers.html)**

## 세 교육을 연결하는 다섯 가지 질문

메인 화면은 다음의 공통 질문을 제시합니다. 각 대상은 자신의 역할과 업무에 맞춰 같은 질문을 적용합니다.

| 구분 | 핵심 질문 | 교육에서 확인할 내용 |
| --- | --- | --- |
| Q1. 문제 정의 | 무엇이 문제인가? | 눈에 보이는 현상과 원인을 구분하고, 확인할 문제와 범위를 정합니다. |
| Q2. 근거 검증 | 근거는 무엇인가? | 원문과 데이터를 대조하며 AI의 설명과 가설이 근거를 갖추었는지 확인합니다. |
| Q3. 해결 방안 | 무엇을 바꿀 것인가? | 현재 업무(AS-IS)에서 개선 업무(TO-BE)로 바꿀 요소와 적용 방법을 정합니다. |
| Q4. 책임 체계 | 누가 실행하는가? | AI의 제안을 검토하고 판단할 사람, 실행 담당자와 인계 기준을 구분합니다. |
| Q5. 측정 및 확산 | 어떻게 점검하는가? | 시간·업무 흐름·품질 지표를 통해 적용 결과를 살펴보고 다음 개선으로 연결합니다. |

## 사이트 이용 방법

1. [메인 화면](https://datathinkinglab.github.io/yuanta-ai-training/)에서 자신의 교육 대상을 선택합니다.
2. **강의 슬라이드 보기**를 눌러 해당 강의로 이동합니다.
3. **이전·다음** 버튼이나 키보드 방향키로 슬라이드를 넘깁니다.
4. **목차 · 모듈 이동**에서 원하는 학습 내용으로 바로 이동합니다.
5. 필요에 따라 **전체화면 보기**, **PDF 출력**, 본문에 연결된 참고자료·실습 팝업을 활용합니다. 본사 팀장·지점장 강의는 **전체 읽기**도 제공합니다.
6. 강의 하단의 **메인 화면** 버튼으로 교육 허브에 돌아옵니다.

메인 화면은 교육 소개, 공통 질문, 대상별 강의 연결로 구성되어 있습니다. 상세 학습 내용과 실습 안내는 각 강의 슬라이드에서 확인할 수 있습니다.

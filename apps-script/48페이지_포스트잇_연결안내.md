# 48페이지 포스트잇 연결 — 기존 Apps Script 업데이트

현재 사용 중인 임원 설문 Apps Script 프로젝트에서 진행합니다. 새 프로젝트나 새 URL을 만들 필요가 없습니다.

1. ExecutiveCode.gs 전체 내용을 기존 Code.gs에 붙여 넣고 저장합니다.
2. 배포 → 배포 관리 → 현재 웹 앱의 수정(연필) → 버전: 새 버전 → 배포를 선택합니다.
3. 기존 /exec 주소를 유지하고 강의 48페이지를 새로고침합니다.
4. QR을 휴대전화로 열어 두 질문을 제출하면 포스트잇으로 나타납니다. 같은 기기에서 수정 제출하면 한 장을 갱신합니다.

기존 setup과 SPREADSHEET_ID가 설정되어 있다면 다시 실행할 필요가 없습니다. 임원마무리응답 시트는 첫 사용 시 자동 생성됩니다. 기존 4페이지 설문 집계와 초기화 비밀번호 속성도 유지합니다.

마무리 응답의 업무·질문은 QR로 참여한 수강생과 강의 화면에 익명으로 공개됩니다. 참여ID·실습기록은 공개하지 않습니다. 공개할 수 있는 일반화된 업무와 질문만 작성하도록 안내합니다. 기존 4페이지 집계 초기화는 마무리 포스트잇을 지우지 않습니다.

## 48페이지 리셋 버튼
업데이트한 ExecutiveCode.gs로 기존 Code.gs를 교체한 뒤 배포 관리 → 수정 → 새 버전 → 배포합니다. 프로젝트 설정 → 스크립트 속성의 POLL_RESET_PASSWORD를 강사용 비밀번호로 지정합니다(기존 설정이 있으면 유지). 48페이지를 새로고침하면 전체 포스트잇 리셋 버튼이 활성화됩니다. 확인 후 비밀번호를 입력하면 기존 답변은 임원마무리응답_보관 시트로 이동하고 화면은 비워집니다. 4페이지 객관식 집계와 실습기록에는 영향을 주지 않습니다. 참가자는 같은 기기에서 다시 제출할 수 있습니다.

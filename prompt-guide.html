무엇을 → 왜 → 어떻게

무엇을

수행할 일과 받을 산출물
동사 + 대상 + 결과
예: 회의 메모에서 후속 실행 목록을 만들어 주세요.

왜

사용 목적과 결과를 읽을 사람
목적 + 독자 + 상황
예: 팀장이 다음 회의에서 진행 상황을 점검하려고 합니다.

어떻게

사용 자료와 작성·확인 조건
자료 + 형식 + 제약 + 완료 기준
예: 담당자·기한을 표로 쓰고 없는 정보는 확인 필요로 표시해 주세요.

항상 세 개의 제목을 붙일 필요는 없습니다. 세 질문의 답이 요청 안에 들어 있는지 확인하세요.

자료·형식·제약·완료 기준을 정합니다

중요한 조건부터 짧고 명확하게 전달합니다

어떤 자료로?

제공한 회의 메모만 사용합니다. 자료에 없는 사실은 만들지 않습니다.

어떤 형태로?

결정사항·후속조치·담당자·기한을 표로 작성합니다.

어디까지 확인?

메모에 없는 담당자나 기한은 “확인 필요”로 표시하고, 각 항목에 근거 문장을 붙입니다.

최신 모델 활용의 핵심: 목표와 제약, 결과 기준을 분명히 하되 불필요하게 모든 중간 과정을 지시하지 않습니다.

유안타증권 · AIbility Academy STEP-UP작성 습관

긴 역할 설정보다 업무 조건을 구체화합니다

기존 작성 습관을 실무 요청으로 다듬기

흔한 요청더 유용한 작성 방법
“당신은 20년 경력의 전문가입니다.”필요한 관점을 명시합니다. 예: 팀 업무 점검 관점에서 누락된 담당자와 기한을 찾아 주세요.
“단계별로 자세히 생각해 주세요.”결과에 필요한 근거와 확인 사항을 요청합니다. 예: 각 제안의 근거와 가정을 함께 써 주세요.
“무조건 질문부터 해 주세요.”결과가 크게 달라질 핵심 정보가 없으면 질문하고, 나머지 누락은 확인 필요로 표시하게 합니다.
“알아서 완벽하게 해 주세요.”완료 기준을 씁니다. 예: 모든 후속조치에 담당자·기한 또는 확인 필요가 표시되어야 합니다.

역할, 과업, 맥락, 출력 형식은 여전히 유용한 점검 요소입니다. 세 질문 안에 필요한 요소를 담으면 됩니다.

가상 회의 메모로 요청을 작성해 봅니다

아래 자료를 AI에 제공한다고 가정합니다

가상 팀 회의 메모
· 업무 요청이 이메일과 메신저로 나뉘어 들어와 누락 여부를 확인하기 어렵다는 의견이 나왔다.
· 김 담당자가 공통 요청 양식 초안을 다음 회의까지 작성하기로 했다.
· 요청 현황을 한곳에서 관리하는 방안은 검토하기로 했으나 담당자는 정하지 않았다.
· 개선 효과를 어떤 지표로 확인할지는 다음 회의에서 논의하기로 했다.

가상 인물·가상 상황이며 실제 유안타증권의 업무 현황을 나타내지 않습니다.

목적·누락 처리·근거가 들어간 요청

실습 요청 예시

[무엇을] 앞의 가상 회의 메모에서 후속 조치와 미결사항을 정리해 주세요.
[왜] 팀장이 다음 회의에서 진행 상황과 추가로 결정할 사항을 점검하기 위한 자료입니다.
[어떻게] 항목·상태·담당자·기한·근거 문장을 표로 작성해 주세요. 실행이 합의된 일과 검토 또는 논의할 일을 구분해 주세요. 메모에 없는 담당자나 기한은 추정하지 말고 “확인 필요”로 표시하세요. “다음 회의까지”는 그대로 쓰고 임의의 날짜로 바꾸지 마세요.

자료와 지시를 구분해 전달합니다. 자료에 없는 정보가 중요한 경우 추가 질문으로 보완합니다.

부족한 부분을 짚어 다시 요청합니다

기준과 차이를 알려주면 수정 방향이 분명해집니다

통합 관리 방안은 도입이 확정된 것이 아니라 검토하기로 한 사항입니다. 상태를 “검토 예정”으로 수정하고, 메모에 없는 담당자와 날짜는 “확인 필요”로 표시해 주세요. 각 행의 근거 문장을 원문에서 찾아 붙이고, 확정된 사실과 제안을 구분해 주세요.

“더 잘해줘” 대신 틀린 부분·바꿀 기준·원하는 결과를 알려줍니다. AI의 자체 점검 후에도 원문 확인은 담당자가 합니다.
